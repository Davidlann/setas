Detalle de las especies seleccionadas

El índice combinado es la media geométrica de hábitat y tiempo para cada especie. Si eliges varias, se muestra el mejor índice entre ellas. Es experimental: no representa una probabilidad.

Sobre estos datos

El hábitat, la lluvia, la temperatura y el pH son estimaciones regionales, no mediciones exactas de cada lugar. El índice meteorológico ya penaliza las mínimas bajo un umbral térmico experimental por especie. La época del año se explica en las guías, pero aún no se usa como factor numérico: cambia con la región, la altitud y el año. Ningún índice calcula una probabilidad ni confirma o descarta fructificación.

Cargando el mapa base…

No recolectes ni consumas una seta basándote en esta guía, una foto o el mapa. Hay especies tóxicas parecidas y la identificación requiere revisar todos los rasgos con una persona experta. Respeta también las normas locales de recolección.
